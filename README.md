# Лабораторна робота №8

Класифікація зображень котів і собак за допомогою згорткової нейронної мережі.
[Умова завдання](https://github.com/UNI-DS/DS-Lab-8).

## Запуск

Python 3.11. Команди для Windows:

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python download_dataset.py
python -m src.tasks
```

У Linux/macOS середовище активується командою `source venv/bin/activate`.

## Модель і дані

Вхід — RGB-зображення 180×180. Три блоки Conv2D → BatchNormalization → MaxPooling2D
мають 128, 256 і 512 фільтрів. Далі: Flatten → Dense(1024, ReLU) → Dropout(0.3)
→ Dense(2, softmax). Оптимізатор Adam, функція втрат categorical crossentropy.

Архів містить 1316 зображень. Для навчання використовуються 1014, для валідації — 112,
для тестування — 190. Випадкові перетворення застосовуються лише до навчальних зображень;
валідаційні й тестові зображення тільки нормалізуються. Класи: `0 = Cat`, `1 = Dog`.

Основний запуск виконує 30 епох із розміром пакета 32 та seed 42. Для підсумкового
оцінювання завантажується модель із найменшою валідаційною втратою.

## Результати

Після 30 епох обрано модель з епохи 23. Тестова точність — **65,26%**
(124 правильні прогнози зі 190), втрата — **0,6534**. Це нижче орієнтовних
70–75% з умови; модель частіше помиляється на зображеннях собак.

У папці `results/` зберігаються:

- `metrics.json` — точність і втрата на тестовій вибірці, параметри запуску.
- `history.csv` — метрики навчання й валідації за кожну епоху.
- `predictions.csv` — справжні класи, прогнози та ймовірності для 190 тестових зображень.
- `training.png` — криві втрат і точності.
- `augmented_images.png` — приклади навчальних перетворень.
- `predictions.png` — приклади прогнозів для обох класів.

Навчена модель зберігається локально у `pets_model.keras`. Зображення й модель
не завантажуються до Git; їх можна відтворити командами вище.

GitHub Actions перевіряє архітектуру, розділення вибірок і навчання протягом однієї епохи.
Збережені результати отримано повним локальним запуском, а не короткою перевіркою CI.
